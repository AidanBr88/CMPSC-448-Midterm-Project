# CMPSC-448-Midterm-Project

Author: Aidan Brown (solo group)

## Project Overview
This project compares a convolutional neural network (CNN) and a long short-term memory network (LSTM) for identifying which LLM generated a response.

The three models being identified are:
- GPT-4
- LLaMA-2-13B-chat
- Falcon-40B-instruct

## Research Questions
- **RQ1:** Can the generator be identified from its response?
- **RQ2:** Does including the user’s prompt improve identification?

## How to Run
1. Download the `.ipynb` notebook from this repository.
2. Upload it to Google Colab.
3. Select a GPU runtime if available.
4. Run the cells in order.
